# Open International Soccer Database

- Дата обращения: 07.10.2026
- Авторы / источник: Dubitzky, Lopes, Davis, Berrar (2019), Machine Learning 108, 9–28 (ключ в refs.bib: dubitzky2019opendb)
- Лицензия / условия: проверить на странице репозитория

## Характеристики
- Объём: 216 743 матча (версия v1.0)
- Охват: 52 лиги в 35 странах
- Период: с 2000 года (с момента, когда лиги перешли на правило «три очка за победу»)
- Содержимое: только базовая информация о матчах; из событий матча только голы
- Связанный конкурс: 2017 Soccer Prediction Challenge: обучение на всей базе, проверка на 206 будущих матчах (с 31 марта 2017 до конца регулярного сезона), метрика Ranked Probability Score (RPS)

## Плюсы
- Большой размер и разнообразие лиг
- Готовый научный бенчмарк: можно сравнить свои результаты с конкурсными

## Ограничения
- Мало признаков: рейтинги команд и форму надо строить самому из счётов
- Нет коэффициентов и данных об игроках (проверить в описании)
