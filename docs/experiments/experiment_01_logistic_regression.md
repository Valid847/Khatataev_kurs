# Отчёт по эксперименту № 1

## Прогнозирование исходов матчей Английской Премьер-лиги с помощью логистической регрессии

## 1. Цель эксперимента

Проверить качество прогнозирования исходов матчей Английской
Премьер-лиги (EPL) с помощью логистической регрессии на основе
результатов последних матчей команд. Также определить влияние количества
предыдущих матчей N на качество модели.

## 2. Исходные данные

Использованы исторические данные EPL за сезоны с 2015/16 по 2024/25.
Исходный набор содержит 3800 матчей.

Целевая переменная: - `H` --- победа домашней команды; - `D` ---
ничья; - `A` --- победа гостевой команды.

Данные объединены, даты приведены к единому формату, матчи отсортированы
по времени.

## 3. Формирование признаков

Для каждой команды учитывались результаты последних N матчей.
Проверялись значения N: `3`, `5`, `10`, `15`, `20`.

Формировались шесть признаков: - `home_wins`, `home_draws`,
`home_losses` --- количество побед, ничьих и поражений домашней
команды; - `away_wins`, `away_draws`, `away_losses` --- количество
побед, ничьих и поражений гостевой команды.

Использовались только результаты матчей, сыгранных до рассматриваемой
встречи. Для матчей одной даты признаки формировались до добавления
результатов этой даты в историю команд. Это предотвращает утечку
информации из будущего. Матчи, для которых не хватало N предыдущих игр у
одной из команд, исключались.

## 4. Методика эксперимента

Данные разделены хронологически: - обучающая выборка --- матчи до 1 июля
2023 года; - валидационная выборка --- с 1 июля 2023 года до 1 июля 2024
года; - тестовая выборка --- начиная с 1 июля 2024 года.

Сравнивались: 1. `DummyClassifier` со стратегией `most_frequent` ---
всегда предсказывает наиболее частый класс обучающей выборки; 2.
`LogisticRegression` с предварительной стандартизацией признаков через
`StandardScaler`.

Использовались метрики Accuracy и Macro F1. Значение N выбиралось по
валидационной выборке. Тестовая выборка оставалась для итоговой оценки.

## 5. Результаты на валидационной выборке

### 5.1. Базовая модель

     N   Accuracy   Macro F1
  ---- ---------- ----------
     3     0.4589     0.2097
     5     0.4587     0.2096
    10     0.4622     0.2107
    15     0.4603     0.2101
    20     0.4639     0.2113

### 5.2. Логистическая регрессия

     N   Accuracy   Macro F1
  ---- ---------- ----------
     3     0.5066     0.3581
     5     0.5253     0.3707
    10     0.5243     0.3794
    15     0.5671     0.4150
    20     0.5722     0.4175

Логистическая регрессия превзошла базовую модель по обеим метрикам для
всех значений N. Лучший результат получен при N = 20: Accuracy ---
0.5722, Macro F1 --- 0.4175. Поэтому для итоговой оценки выбрано N = 20.

## 6. Итоговая оценка на тестовой выборке

После выбора N = 20 модель обучена заново на объединённых обучающей и
валидационной выборках. Тестовая выборка содержала 360 матчей.

Результаты: - Accuracy --- 0.5417; - Macro F1 --- 0.4056.

Матрица ошибок:

  -----------------------------------------------------------------------
  Фактический         Предсказана H      Предсказана D      Предсказана A
  результат                                            
  -------------- ------------------ ------------------ ------------------
  H                             122                  0                 27

  D                              57                  0                 29

  A                              52                  0                 73
  -----------------------------------------------------------------------

Модель правильно определила 122 победы домашних команд и 73 победы
гостевых команд. Ни одна ничья не была предсказана правильно: модель не
выбрала класс D ни в одном тестовом матче. Поэтому одной Accuracy
недостаточно для оценки качества модели.

## 7. Анализ вероятностей ничейного исхода

Средняя предсказанная вероятность ничьей для матчей, которые фактически
закончились вничью, составила 0.2295. Для матчей без ничьей --- 0.2293.
Разница практически отсутствует.

В 187 из 360 тестовых матчей ничья занимала второе место по
предсказанной вероятности, но ни в одном матче не занимала первое место.

Это означает, что модель присваивает ничьей ненулевую вероятность,
однако используемые признаки не позволяют ей выделять матчи с ничейным
исходом.

## 8. Выводы

1.  Логистическая регрессия показала лучшие результаты по сравнению с
    базовой моделью для всех проверенных значений N.
2.  Лучший результат на валидационной выборке получен при N = 20.
3.  На тестовой выборке Accuracy составила 0.5417, Macro F1 --- 0.4056.
4.  Модель лучше распознаёт победы домашних команд, хуже --- победы
    гостевых команд, а ничьи не распознаёт.
5.  Средняя вероятность ничьей практически одинакова для матчей с
    фактической ничьей и без неё.
6.  Шести признаков, основанных только на количестве побед, ничьих и
    поражений, недостаточно для качественного прогнозирования всех трёх
    исходов.

## 9. Ограничения и дальнейшая работа

В эксперименте не учитывались забитые и пропущенные голы, разница мячей,
результативность команд, отдельная статистика домашних и гостевых матчей
и рейтинги команд.

В следующем эксперименте планируется добавить признаки, связанные с
голами и результативностью команд, а затем сравнить качество моделей.
Отдельное внимание будет уделено улучшению распознавания ничьих.

## 10. Итог

Первый эксперимент показал, что логистическая регрессия превосходит
базовый классификатор при прогнозировании исходов матчей на основе
последних результатов команд. Однако текущего набора признаков
недостаточно для распознавания ничьих. Полученные результаты станут
отправной точкой для дальнейшего расширения признакового пространства и
сравнения алгоритмов машинного обучения.
